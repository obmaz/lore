# 소설 제작실

[웹에서 제작실 열기](https://obmaz.github.io/lore/novel/studio/). 사용자가 공개 게시를 허용한
작가용 화면이며, 로그인 없이 전편 스포일러와 원본 JSON을 확인할 수 있습니다.

[오프라인 제작 화면](generated/index.html)을 내려받아 브라우저로 열 수도 있습니다. **이 HTML 하나만 있으면**
원고·목차·그래프·설정 조회를 사용할 수 있습니다. 서버·게임·외부 서비스가 필요 없습니다.
GitHub의 파일 보기 화면은 HTML을 실행하지 않으므로 Raw 파일을 저장해서 여세요.

## 한 화면에서 보는 자료

| 메뉴 | 내용 |
| --- | --- |
| 작업 현황 | 큰 구성·소단락·원문 연결·상세 본문의 서로 다른 진행 단계 |
| 소설 읽기 | 실제 집필한 최신 본문. 요약·분기 시범과 구분 |
| 목차·장별 구성 | 전체 장 목차, 장의 큰 이야기, 소단락 주요 내용·필수 결과 |
| 분기 · 그래프 | 장별 그래프·조건/결과·전편 분기 미리보기. 미리보기는 요약과 선택 시범이며 완성 소설 아님 |
| 출판 편집 순서 | 예시 경로의 주요 소단락과 실제 문단 참조 순서 |
| 인물·세계 설정 | 인물·관계·무기·마법·적·지명·공개 시점 검색과 상세 카드 |
| 원본 JSON·작업 규칙 | 항목의 원본 위치, 파일/문단 JSON 조회·다운로드, 집필 지침 |

자료 종류나 판본을 바꾸면 같은 화면에 표시합니다. 장 선택은 구성과 그래프 사이에서 유지합니다.
설정 검색은 선택한 종류의 이름·직업·성향·ID·상세 내용에 적용합니다.
원본 보기 버튼은 해당 문단의 JSON Pointer로 이동합니다. 다운로드한 문단에는
`.excerpt.json`을 붙여 전체 원본 파일과 혼동하지 않게 합니다.

메뉴·장·인물 상세·설정 탭·JSON 탐색은 주소의 `#/…`와 브라우저 기록에 연결됩니다.
뒤로/앞으로와 `이전 화면` 버튼으로 제작실 안의 이전 탐색을 복원하고, 현재 주소를
북마크해 같은 장·설정으로 돌아올 수 있습니다. 처음 화면에서의 뒤로 가기는 일반 브라우저와 같습니다.
설정은 목록에서 하나를 골라 핵심 설정·원작 정보·관계/공개를 나누어 읽습니다.
핵심 설정은 이름·나이·외모·종족·성격·출신·설정의 대체값을 우선 표시합니다.
성주는 목록·상세에서 `동욱`으로 표시하고 원작 이름 `Lord Ahn`은 원작 정보에 보존합니다.
대체값이 없으면 기존 카드의 값을 쓰며 둘 다 없으면 미상으로 남깁니다.
검색 입력은 기록을 글자마다 늘리지 않으며 근거·편집 메모는 항목의 `근거` 버튼으로 펼칩니다.
짧은 설정은 항목·값·출처 표시를 한 줄로 모으고, 상세 패널의 실제 폭에 따라 1~2열로 배치합니다.
긴 설명·목록은 전체 폭을 쓰며 모든 값·근거·추가 메타데이터는 그대로 보존합니다.
미상 값의 반복 배지는 생략하고 분류·검토 상태는 근거 안에 남깁니다. 이름·원어·ID·목록 복귀는
상단 한 줄로 모아 기본 정보까지의 스크롤을 줄입니다. 글자를 더 작게 만드는 방식은 쓰지 않습니다.
`장별 분기 그래프`가 기본 탭입니다. 장을 고르면 소단락·질문·선택·합류·후속 반응을 상자와 화살표로 표시합니다.
박스를 클릭하거나 Enter/Space를 누르면 본문, 질문과 선택지, 조건, 상태 변화와 원본 참조를 확인합니다.
데스크톱은 오른쪽 상세 패널, 좁은 화면은 그래프 아래 패널을 사용합니다. 보라색 영향선은 선택한 박스와
연결된 선만 보여 주며 닫기/Escape로 선택을 해제합니다. 내용은 장별 그래프로 통합했고 비교 타임라인 탭은 제거했습니다.
그래프와 상세 패널 사이 경계선을 드래그하면 좌우 폭을 조절합니다. 좁은 화면에서는 위아래 높이를
조절합니다. 경계선에 초점을 두고 방향키로도 조절하며 두 번 클릭하면 기본값으로 돌아갑니다.
조절한 크기는 장·메뉴를 바꿔도 유지합니다. 브라우저 세션 저장이 가능하면 새로고침에도 유지됩니다.
후속 문단은 실제 등장하는 장·소단락에 두며 다른 장 연결 버튼으로 해당 문단을 선택합니다.
공용 문체는 작업 현황의 `공용 문체 A / B`에서 확인합니다. 기준·원고 연결은
`writing/styles.json`, A 정의는 `writing/project.json#/style`, B 정의는 `styles.json#/profiles/B`입니다.
`조건 · 결과` 탭은 **같은 장**의 선택 뒤 이야기, 필수 합류, 후속 반응, 본줄기 조건과 미구현 후보를
원래 분기 JSON에서 가져옵니다. 조건·상태 변화·추가 메타데이터는 펼쳐 보고 해당 원본으로 이동할 수 있습니다.
장과 탭 선택은 뒤로/앞으로·북마크에 유지됩니다. 이전 `#/branches` 주소도 이 상세 탭으로 연결합니다.

제작실의 기본 글자는 14px, 메뉴·버튼은 12~13px, 화면 제목은 22~24px로 맞췄습니다.
카드와 단락 간격도 줄였으며 모바일 메뉴의 터치 영역은 44px를 유지합니다.
이 조정은 제작실 UI에만 적용하며 별도 독자 판본·원고의 글자 크기는 바꾸지 않습니다.

## 원본과 공개 경계

`studio.plan.json`은 메뉴·표시 설명을 정의하는 편집 입력입니다. 자료의 실제 원본은
기존 집필/설정 JSON이며 제작실에 또 다른 이야기 원본을 만들지 않습니다.
`generated/index.html`은 그 자료와 읽기본을 묶은 **읽기 전용 생성 스냅샷**입니다.
화면에서 원고를 수정하거나 저장소에 자동 저장하는 기능은 없습니다.
원본 파일을 편집·검증한 뒤 재생성해야 변경이 반영됩니다.

작가용 전편 스포일러입니다. 입장·확인 버튼 없이 바로 제작실이 열리며 파일 안에는
전체 자료가 있습니다. 기존 독자 `/novel/`에는 제작실·인물 마스터를 추가하지 않습니다.
별도 `/novel/studio/`는 사용자가 공개 허용한 작가용 경로이며 접근 제어가 없습니다.
`publication.json`에 게시 대상·주소·사용자 요청·공개 범위를 기록합니다.
`author_only`는 자료의 용도이지 인증 설정이 아닙니다.
소설 읽기의 `읽을 판본`에는 A 1~3장과 B 1~2장 초고만 표시합니다. 목록은 `styles.json`의
집필 장 목록을 읽습니다. 목차·장별 분기 그래프는 공통 하나이며 B는 장별 창작 본문 레이어만
별도로 재집필했습니다. 미집필 B 장을 A로 자동 보충하지 않습니다.
전편 원문 연결·구성 개요·분기 시범은 별도 자료로 구분합니다.
15장 상세 본문·출판 경로·페이지가 완성되었다는 뜻이 아닙니다.
원작 밖의 설정·추론과 증언·공개 조건은 기존 카드의 표시를 그대로 사용합니다.

## 갱신과 검사

소설 읽기는 최신 소설 본문만 표시한다. 전편 곁가지 시범은 분기 · 그래프 → 분기 미리보기에서 확인한다.
구성·원문 자료는 별도 메뉴/원본 조회로 구분한다. 옛 도입부·소편·경로별 HTML은
생성 대상에서 제외하고 기존 매니페스트의 해시가 일치할 때만 정리한다. 수동 수정된
출력은 삭제를 거부한다. 원고 JSON과 원작 스크립트, 검증용 읽기 경로는 보존한다.

`novel/`에서 실행합니다.

```sh
python3 tools/writing.py validate
python3 tools/writing.py export
python3 tools/writing.py export --check
python3 tools/studio.py export --check
python3 tools/check_studio_browser.py
```

`writing.py export`에 생성이 포함되므로 별도로 자료를 복사할 필요가 없습니다.
기존 읽기본이 최신이면 `studio.py export`만으로 제작실을 생성할 수도 있습니다.
수동 편집된 제작실 출력은 덮어쓰지 않고 멈춥니다. 변경을 보존하고 원래 입력에 옮깁니다.
브라우저 검사는 선택적인 Playwright·Chromium 환경에서 수행하며 일반 열람에는 필요 없습니다.
