# 소설용 스크립트 대체본

`registry.json`은 이름의 대체값처럼 A/B 독자 본문과 EPUB이 함께 쓰는 스크립트 편집 사전입니다.
원고의 보존 원문과 `materials/scripts.json`은 수정하지 않습니다.

- 키: 원작 연결 표시 묶음의 첫 블록 ID. `source_block_ids`는 같은 묶음의 원문 블록을 순서대로 참조합니다.
- 근거: `source_literal_ids`와 `source_sha256`은 **표시명 치환 전 원문**을 검토한 지문입니다.
  원문·구간이 달라지면 자동으로 새 대체본을 승인하지 않고 재검토를 요구합니다.
- 수정: `writing_overrides.text`의 span 배열을 집필합니다. 이름·지명·장비는 `ref`를 씁니다.
  성주의 자기소개에는 이름의 받침을 따르는 `이오/요` 조사도 지원합니다.
- 조회: 대체 텍스트가 있으면 먼저 쓰고, 키가 없거나 `text: null`이면 기존 원작 연결 표시로 돌아갑니다.
  원작 결과를 서술하는 `prose-presentation.json`의 문단·앞뒤 서술·화자·조건은 유지합니다.
- 출처: 각 항목은 `source_adaptation / proposed`이며 해석 추가의 메타를 남깁니다.
  새 사건·성격·능력·보상을 대체 대사로 몰래 부여하지 않습니다.

현재 게임/아바타 자기소개, 문 앞의 게임 입력 질문, 프로그래머 크레딧을 소설용으로 옮겼습니다.
크레딧의 실명은 원작 창작자 표기이며 등장인물 카드나 세계관의 새 인물이 아닙니다.

수정 후 `novel/`에서 `python tools/writing.py export`로 두 웹 판본과 B EPUB을 함께 갱신합니다.
제작실의 원본 JSON 메뉴에서도 이 사전을 조회할 수 있습니다.
