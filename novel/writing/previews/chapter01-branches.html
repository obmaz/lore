집필 본문 분기 안내 · 1~2장 · 작가용

작가 전용 · 분기와 선택 동료의 이탈 스포일러 포함.

선택이 아닌 연속 서사

문턱의 망설임·거절·다시 묻고 결심하는 대화·출구 이동은 한 독서 구간으로 자동 연결한다. 원작 응답은 서로 다른 대화 시점에 보존한 창작 각색이며 독자의 거절/수락 선택이 아니다. 거리의 추가 동굴 설명과 돌아서는 길의 격려도 버튼 없이 이어진다. 원문을 읽기 위한 재질문·재인사·확인·돌아가기 메뉴를 만들지 않는다. 지역 방문, 동료 영입, 접근법, 직업별 행동, 실제 보물 획득처럼 경험이나 후속 상태가 달라지는 선택은 유지한다.

큰 줄기와 적용 범위

이 오버레이의 범위는 1장이다. 성주 설명→첫 부탁→출발→동굴 중심 확인→귀환→성공 보고의 필수 본줄기를 유지한다. 실제 집필한 2장은 series.json에서 별도 원고를 참조해 앞 장의 상태와 이어 읽는다.

탐방 순서·자동 진행

무기고나 한 지역을 고른 뒤에는 다음 본줄기로 합류한다. 같은 탐방 허브로 돌아가 나머지 선택을 수집하지 않는다. 의뢰 전 주점과 의뢰 후 탐방은 다른 시점의 행동이며 방문/증언을 실제 경로대로 기록한다. 단일 진행은 확인 버튼 없이 자동으로 이어진다.

네 시작 동료·직업·무기

네 인물은 사용자가 지정한 새 집필 인물이며 기존 원작 초기 후보를 바꾼 것이 아니다. 이름·직업·장비는 참조 사전 ID로 연결한다. 현재 동행 여부+현재 무기 ID+실제로 역할을 활용했는지를 모두 만족해야 동굴과 보고의 후속 반응이 나온다. 마술 지팡이에 원작에 없는 주문을 자동 부여하지 않는다.

무기고

방문/미방문과 먼저/나중 순서를 기록한다. 원작은 무기 0이고 직업 5가 아닌 실제 인원만 기본 무기 1을 지급한다. 새 네 동료는 이미 직업 무기를 갖고 있어 바꾸지 않는다. 주인공의 원작 클래스·무기 상태는 미정이므로 원작 지급 수치를 추정하지 않는다. 화면의 원문 지급 문구와 실제 소지 상태를 구별한다. 실제 동행 중인 매드 조가 비무장일 때는 원작 class=8, weapon=0 근거에 따라 기본 무기 1을 지급하며, 도망간 조에게는 지급하지 않는다.

선택 동료 한 자리

1장의 원작 6번 선택 동료 자리를 추적한다. 스켈레톤은 즉시 수락/거절 또는 추가 대화를 한 뒤 별도 결정 장면에서 답하고 앞으로 합류한다. 같은 제안으로 돌아가 영입과 거절을 모두 수집하지 않는다. 기존 동료가 있다면 실제 헤어짐 뒤 새 동료를 받는다.

수감소 접근·매드 조

원작 면회 금지와 수감자/도둑/매드 조 대사를 보존한다. 정확한 원작 내부 접근 조건은 미확정이라 면회 재요청 또는 나무받침 일을 거드는 접근은 이 소설 판본의 창작 연결이다. 매드 조 영입→정문이면 원작처럼 병사 대치가 발생하고 매드 조가 도망간다. 일 돕기 경로의 조용한 이탈은 추가 규칙이며 병사 전투가 발생하지 않아 동행을 유지할 수 있다. 영입 경험 bit2와 현재 동행을 분리한다. 첫 병사 2명/재접근 7명 대사는 다른 분기에 배치한다. 전투 결과 선택은 자동 승리·게임 수치 검증이 아닌 집필 시뮬레이션이다.

소문·복선·스포일러

방문한 곳의 대사만 읽기 화면과 경험에 등장한다. NPC의 로드 안 평가·특공대 회고·수감자 증언을 세계의 확정 진상으로 합치지 않는다. 주니어 안타레스·폴라리스·성전 이야기는 대사를 들은 복선이며 후속 인물 합류/마법 습득이 아니다. 전편 인물카드·관계 마스터는 독자 파일에 넣지 않는다.

동굴 보물

중심 확인 뒤 탐방을 고르면 여섯 금화 발견을 하나의 연속된 탐색으로 읽는다. 원작 액수와 일회성 효과는 그대로다. 방패의 실제 담당자/장착하지 않기만 선택하고 귀환으로 합류한다. 방패를 장착하지 않아도 이미 수집한 금화를 회수하거나 다시 지급하지 않는다. 새 이동·연결은 창작 서사이며 원작 벽 통과 능력을 추가하지 않는다.

원문 누락·이름 변경·경로 저장

원문 발생 ID별로 본문/선택 ID를 기록한 chapter01-coverage.json을 생성한다. 모든 정적 대사는 해당 분기에 보존하며 서로 배타적인 문장을 한 경로에 합치지 않는다. 동적 주인공 이름·금액·장착자와 미정 호칭은 원문 조각과 별도 표시 규칙을 둔다. 저장 파일은 판본 해시+선택 ID 경로만 받고 지식/아이템 상태를 재계산한다. 이름 변경은 names.json→참조 재생성→읽기본 재생성으로 전체 반영된다.

다음 챕터에 전달할 것

동행과 현재 장비, 역할·방문·증언 경험, 실제 금화·방패, 임무 단계·보상 여부를 series.json의 명시적 공유 상태 계약으로 2장에 이어 준다. 2장 영입/창/전투 접근은 한 번의 결정 뒤 앞으로 합류한다. 3장 이후 상세 산문은 아직 집필 전이다.

주점 한 소편 · 서사는 길게, 행동 선택은 드물게

입장·인사·음료 권유·원작 주점 말들을 하나의 긴 독서 구간으로 자동 연결한다. 주점이 첫 탐방이면 음료 인사, 다른 탐방 뒤면 가까운 인사로 이어지는 창작 배치다. 독자가 인사 방식을 고르거나 한 방문에 두 인사를 모두 확인하는 메뉴는 없다. 끝에서 노인에게 말을 걸거나 떠나는 행동만 고른다. 전자는 기존 증언/지식 사건으로, 후자는 퇴장 서사로 이어진다. 원작 대사 ID는 유지하며 새 감각·행동·심리는 창작 제안이다. 다른 짧은 지역 장면까지 재집필한 것은 아니다.
