# 실제 집필한 소설 · 정방향 선택

[선택하며 읽기](../previews/chapter01-interactive.html)를 다운로드해 브라우저에서 연다.
서버·계정·게임 실행·빌드가 필요 없다. 화면 아래 선택지를 누르면 선택한 경로만
누적해 읽는다. 뒤로 가기·처음부터·경로 저장/불러오기를 지원한다.
인쇄/PDF 저장 버튼은 없다. 장 제목은 `../storyboard/chapters.json`의 현재 장을 참조한다.
전편 큰 구성의 제목·필수 사건은 작가용으로 미리 정하고 후속 본문은 별도로 집필한다.
선택 후에는 새로 추가된 첫 장면의 시작으로 스크롤과 키보드 초점을 옮긴다.
자동 진행이 이어져도 중간의 새 본문을 건너뛰지 않는다. 뒤로 가기와 경로 불러오기는
해당 장면의 시작으로, 처음부터는 첫 장면으로 이동한다.
GitHub의 HTML 파일 화면 자체는 선택지를 실행하지 않는다.

읽기 화면은 실제 집필한 A 1~3장 초고를 이어 보여 준다. 15장 개요와 곁가지 시범은
제작실의 분기 미리보기이며 완성 소설이 아니다. 1장 본문은 기존 원고와 보충 산문을
참조하고, 2장 본문은 `../quests/lastditch_pyramid.json`의 여섯 집필 묶음이다.
`series.json`은 본문을 복사하지 않고 노드·필수 장면·공유 상태·표시 묶음을 연결한다.
문체와 의미 검토 및 출판 승인은 남아 있다.

공용 문체는 `../styles.json`의 A/B다. 기존 본문과 3장은 A이고, B 1장은
`../variants/B/chapter01.json`의 별도 창작 블록 레이어다. [A/B 통합 독서 화면](../previews/novel-reader.html)에서
판본을 고를 수 있다. 질문·선택·결과·원작 대사·이름 참조는 공통이며 B는 1장 끝에서 멈춘다.
[판본 작업 안내](../variants/README.md)를 참조한다.

## 반드시 거치는 본줄기

`chapter01.json#main_story`는 필수 장면 17개의 **순서**와 **첫 방문 필수 본문 ID**를
선언한다. 성주 접견 → 과거 설명 → 첫 의뢰 → 출발 → 동굴 중심 확인 → 귀환/보고 →
다음 부탁은 어떤 선택을 하든 빠지지 않는다. 탐방·동료·역할·보물 선택은 그 사이에서
합류한다. 선택 지역을 모두 방문할 필요는 없고, 방문하지 않은 경험도 생기지 않는다.
본문은 기존 원고를 참조하므로 필수 목록에 문장이나 인물/무기 이름을 복사하지 않는다.

의뢰 전 노인 장면에는 안뜰로 돌아가는 출구만 보인다. 의뢰 후 같은 증언 장면을
다시 사용할 때만 탐방으로 돌아가는 출구가 보인다. 공유 장면 때문에 성주 접견을
건너뛰는 식의 연결을 막는다. 확인 버튼·메인/서브 선택 메뉴를 추가하지 않는다.

내보내기 전에는 필수 장면을 건너뛰거나 순서를 바꾸는 연결, 본줄기 전 조기 종료를
거부한다. `guard_states`에 선언한 임무 단계는 실제 초기값/설정 효과를 추적하고,
나머지 조건은 가능하다고 보수적으로 처리하는 유한 그래프 검사다. 추적 상태에
증가/집합 효과를 추가하면 검사부터 재설계해야 하므로 현재는 스칼라 `set`만 허용한다.
화면과 경로 재생에서도 첫 방문 필수 본문이 실제 표시됐는지, 이후 필수 장면이나
챕터 끝으로 건너뛰지 않았는지 다시 검사한다. 보물 탐방 뒤 중심부 재방문처럼 이미
표시한 대사를 반복하지 않는 것은 허용한다. 저장 파일에 완료 상태를 따로 받지 않는다.

[작가용 분기 안내](../previews/chapter01-branches.html)에는 실제 제목을 참조한 순서표,
[반영표](../previews/chapter01-coverage.json)에는 본줄기와 검사 범위가 함께 생성된다.
[공용 템플릿](../templates/main-story.template.json)을 다음 챕터에서도 사용하되 현재
실행 적용은 현재 집필한 A 1~3장이다. 필수 목록 자체는 편집 검토 대상이며 이 검사는 독자가
글을 실제로 읽었다거나 모든 산문의 의미/원작 조건이 검증됐다는 뜻은 아니다.
현재 1장 오버레이는 revision 9이며 연결 판본은 `series.json`을 함께 참조한다. 정방향 분기와 자동 연결을 갱신했으므로 이전
판본의 저장 파일은 다시 사용할 수 없다. 본줄기의 필수 장면 17개는 그대로다.

## 첫 장 본줄기의 집필 인계

`episodes.json#chapter_units`는 스토리보드의 8소단락을 실제 본문 노드와 연결한다.
제목·원문·본문·인물 이름을 복사하지 않는다. 기존 `menace-01~06`은 의뢰 이후의
여섯 집필 묶음이므로 소단락 번호와 다른 체계다. `handoff`에는 적용 문체 revision,
입력 revision과 남은 보강 범위를 기록했다. 이번에는 도착·접견, 네 시작 동료의
행동과 장비, 이동·동굴 통과·귀환 보고를 보강했다. 본줄기는 긴 초고지만 모든
선택 탐방까지 장편화됐거나 문체·출판 승인이 끝난 것은 아니다.

## 길게 읽고 드물게 선택하기

전 장의 공통 기준은 `../project.json#branch_policy`다. 첫 장 탐방은 한 지역을 고른 뒤
출발로 합류하고, 역할도 한 접근법만 고른다. 다른 선택지를 수집하려고 같은 허브로 돌아오지 않는다.
동굴의 여섯 금화 발견과 방패 확인은 한 탐색으로 연속 서술하며, 실제 장착 담당자/장착하지 않기만
선택한다. 금화의 원래 취득 효과와 원문은 보존하고 확인용 단락 제목도 묶어 표시한다.
유효한 선택이 하나인 장면은 버튼과 ‘선택:’ 표시 없이 자동 연결한다. 다른 결과의 재독은
명시적인 이전 선택 되돌리기/처음부터만 허용한다. 원작의 재전투는 별도 실제 재시도 장면이다.

문턱의 “잠깐 더 생각 → 돌아가기 → 다시 대답” 메뉴는 없다. 망설임과 짧은 거절,
다시 묻고 결심하는 대화를 연속 산문으로 읽고 바깥 출구의 동료 제안으로 이어진다.
원작의 거절/수락 응답을 서로 다른 대화 시점으로 옮긴 **창작 각색**이며 원작의
동일 질문에 두 답을 동시에 한 것으로 처리하지 않는다. 겁이 없어져야만 나서는
것은 아니라는 연결 심리는 창작 장면이지 고정 인물 성향이나 능력 추가가 아니다.
거리의 동굴 추가 설명과 격려자의 배웅도 재질문·재인사 버튼 없이 이어진다.
거리/격려 방문은 각각 1회만 세고 금화·아이템·추가 능력을 주지 않는다.
자동 이동 ID는 경로 재생을 위해 기록하지만 화면에는 독자의 “선택:”으로 표시하지 않는다.
단순 응답·확인 플래그만 달라지는 우회는 새 분기로 만들지 않는다. 지역 방문·영입·
접근법·직업별 행동·보물처럼 경험이나 후속 결과가 달라지는 행동 선택은 유지한다.

주점 한 소편부터 이 기준을 적용했다. 입장 → 인사/음료 권유 → 탁자 사이의 대화를
약 4천 자의 연속된 독서 구간으로 읽고, 끝에서 노인에게 말을 걸지 떠날지만 정한다.
인사 방식과 원문 한 줄을 고르는 버튼은 나오지 않는다. 자동 연결을 독자의 선택으로
표시하지 않으며, 한 방문에서 다른 인사를 다시 확인하는 순회도 없다.
말을 거는 경로는 기존 노인의 증언으로, 떠나는 경로는 별도의 퇴장 서사로 이어진다.

주점이 첫 탐방이면 음료 인사, 다른 곳을 먼저 마쳤으면 가까운 인사가 이어진다.
이 배치는 원작의 무작위 인사를 집필 흐름에 맞춰 재배치한 **창작 조건**이다.
두 원문 모두 보존되어 각각의 경로에 도달 가능하다. 추가 공간·동작·심리·응답은
`authored` 초고이며, 음료 구매/섭취나 금화·장비 변화는 새로 부여하지 않는다.
[소편과 연속성 메모](episodes.json)는 실제 본문 노드를 참조하고 본문을 복사하지 않는다.
다른 짧은 지역 장면은 아직 같은 방식으로 재집필하지 않았다.

## 분기가 어떻게 동작하는가

| 선택 | 변화 | 이후 영향 |
| --- | --- | --- |
| 무기고 / 다른 지역 / 생략 | 한 지역의 실제 방문·지급 기록 | 네 직업 무기 유지. 조건을 충족한 동료에게만 지급 |
| 한 지역 탐방 / 바로 출발 | 방문한 지역과 탐방 횟수 | 그곳 대사·증언만 경험한 뒤 앞으로 합류 |
| 스켈레톤 즉시 수락 / 대화 후 결정 / 거절 | 사전 대화 경험·현재 선택 동료 | 동행한 경우만 기존 동굴/귀환 대사. 거절 후 재영입은 없음 |
| 수감소 재요청 / 일 돕기 | 접근 방식 | 매드 조의 영입 제안은 같지만 이탈 방법 선택이 달라짐 |
| 매드 조 수락 / 거절, 정문 / 조용한 이탈 | 영입 경험·현재 동료 자리·이탈 | 정문 대치에서 원작처럼 도망. 조용한 이탈은 창작 경로로 동행 유지 가능 |
| 네 동료의 직업별 방법 | 실제 동행 + 해당 무기 + 역할 활용 경험 | 동굴 진행과 귀환 보고의 보충 문단 변화 |
| 금화 찾기 / 방패 장착자 / 취소 | 지점별 일회성 기록·금액·장착자 | 실제 획득물만 귀환과 다음 챕터 인계에 남음 |

탐방 횟수는 지역 하나를 마칠 때 1회 증가한다. 지역 안에서 자동으로 이어지는 인사나 대화를
더 듣는 것은 별도의 1회가 아니다. 탐방을 마치면 출발로 합류하며 같은 탐방 메뉴로
돌아가 모든 지역을 수집하지 않는다. 이동을 잇는 새 장면은 **집필용 추가**다.

2장은 도착/의뢰 → 주민과 가족의 증언 → 동료 제안 → 동굴/창 → 대결 → 귀환 보고 →
다음 관문으로 연결한다. 동료 영입/정원 초과 시 교체, 창의 담당자/놓아두기, 함께 버티기/
상대 압박 나누기는 실제 다른 행동이다. 영입하지 않은 인물은 뒤의 동료 반응에 나오지 않는다.
창의 옛 업적은 새 능력의 보장이 아니고, 무기·전투 반응은 실제 장비 조건으로 표시한다.
원문 전투수도사 제한은 보존하되 현재 인물의 미정 직업을 임의로 그 직업이라 확정하지 않는다.
피라미드의 선택 금화 7곳·공유 상점/전투 UI는 이 본문 실행 범위 밖이며 원문 자료에 보존한다.

선택 동료는 원작 6번 자리 하나로 관리한다. 매드 조가 있는데 스켈레톤을 받으려면
기존 동행과 헤어짐을 확인한다. 두 선택 동료를 같은 자리에 동시에 넣지 않는다.
매드 조의 과거 영입 경험과 현재 동행 여부는 별개다. 도망간 인물이 이후 말을 하거나
같이 들은 적 없는 접견실 정보를 자동으로 아는 일을 막는다.

지팡이는 바닥과 울림 확인에 사용한다. 도끼로 원작 고정 벽을 파괴하거나 지팡이가
자동으로 원작의 모든 주문을 쓰는 설정은 추가하지 않았다. 무기 위력도 미정이다.

## 원문은 모두 어디에 있는가

보존 원문은 `../../materials/scripts.json`, 기본 본문은 `../quests/`에 있다.
[chapter01.json](chapter01.json)에는 추가 본문·원문 발생 ID·이름 위치 참조·조건·효과를
둔다. 정확한 범위는 `scope`와 `source_refs`이며 다음을 포함한다.

- LORE 성의 정적 대사: 위험 경고·소문·주점·유골·수감자·도둑·영입·문턱·격려·성주.
- MENACE 입구·중심부, 선택 금화 여섯 곳과 황금의 방패.
- 호출된 금화 표시/거절 문구와 도입부 기본 대사.

[대사 반영표](../previews/chapter01-coverage.json)는 **발생 ID별** 본문 블록/선택 ID를
가리킨다. 서로 배타적인 첫/재방문 대사·인사·수락/거절은 각 조건의 분기에 있다.
한 번의 독서에서 모든 배타 대사가 동시에 나오는 것은 아니다.
비어 있지 않은 대사/선택 라벨/문자 변수 조각이 범위 안에서 빠지면 검증이 실패한다.
빈 레이아웃·선언·제어 문자열은 이유와 함께 `non_story`로 기록한다.

이 반영 완료는 **A의 명시한 1~3장 / B의 명시한 1장 정적 스크립트 범위**에 한정된다. 공유 상점·훈련·회복·무작위 전투
메뉴와 후속 퀘스트 전체를 반영/검증했다는 뜻은 아니다. 원작에서 내부 접근 조건이
미확정인 수감소·벽 안쪽 이동은 창작 연결로 표시했다. 소설용 병사 전투 결과 선택은
게임 전투 수치 시뮬레이터가 아니다. 모든 산문의 의미 검증은 별도의 편집 작업이다.

동적 주인공 이름·금화 금액·방패 장착자는 `display_insertions`로 표시한다.
보존 문자열과 발생 ID는 그대로이고, 현재 이름/값을 넣은 표시는 각색이다.
미정 성별에 따른 원작 호칭 변수는 `[호칭 미정]`으로 남긴다. 미래 인물의 실제 합류,
마법 습득, 로드 안에 대한 최종 진상은 소문/증언을 듣는 것만으로 확정하지 않는다.

## 수정 위치와 다음 챕터 규칙

- 공용 이름: `../../reference/names.json`. 무기/인물 설정: `../../reference/analysis.json`.
- 선택 조건·효과·추가 문단: `chapter01.json`. 형식: `overlay.schema.json`.
- 작가용 설명: `branch_guide`. 독자용 동작: `reader.js`. 생성 HTML은 직접 고치지 않는다.
- 연속성: 합성 시 원래 사건/지식 계약을 유지하고 추가 사건은 경로에서만 발생한다.
  첫 방문 필수 대사를 재방문에 반복하지 않을 때는 `conditional_required`로 원문 필수
  조건을 명시한다. 조건을 바꿔 필수 대사를 숨기면 계약 검증이 실패한다.

다음 챕터는 인계 패킷의 동행/선택 자리·현재 무기 ID·역할 경험·방문 목록·들은 증언·
금화/방패 장착자·임무 단계/보상 여부를 이어받아야 한다. 카드의 전편 설정을 경로의
지식으로 복사하지 않는다. 새 장면의 동료 반응은 실제 동행 여부와 필요한 장비 ID를
함께 검사하며, 같은 영입/아이템/보상 사건을 다시 지급하지 않는다.

경로 저장 파일에는 `fingerprint`와 선택 ID 목록 `route`만 있다. 임의 소지품·지식·
미래 사건을 받아들이지 않는다. 판본이 바뀐 저장 파일은 거부한다. 저장은 사용자가
다운로드를 눌렀을 때만 실행하며, 외부 네트워크나 자동 브라우저 저장은 사용하지 않는다.
독자 HTML에는 집필한 A 1~3장 분기 원고와 공개 표시명만 넣고 전편 카드/관계/진상 마스터는
넣지 않는다. 아직 선택하지 않은 분기는 화면에서 숨겨지지만 오프라인 파일의
소스를 직접 검사하면 확인할 수 있다. 비밀 보안 저장소가 아니라 집필 검토용 판본이다.
