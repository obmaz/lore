# 첫 챕터 선택형 집필

[선택하며 읽기](../previews/chapter01-interactive.html)를 다운로드해 브라우저에서 연다.
서버·계정·게임 실행·빌드가 필요 없다. 화면 아래 선택지를 누르면 선택한 경로만
누적해 읽는다. 뒤로 가기·처음부터·경로 저장/불러오기·인쇄/PDF 저장을 지원한다.
선택 후에는 새로 추가된 첫 장면의 시작으로 스크롤과 키보드 초점을 옮긴다.
자동 진행이 이어져도 중간의 새 본문을 건너뛰지 않는다. 뒤로 가기와 경로 불러오기는
해당 장면의 시작으로, 처음부터는 첫 장면으로 이동한다.
GitHub의 HTML 파일 화면 자체는 선택지를 실행하지 않는다.

적용 범위는 도입부부터 첫 탐사 성공 보고와 다음 부탁의 경계까지다.
큰 줄기는 성주 설명 → 의뢰 → 출발 → 동굴 중심 확인 → 귀환 → 성공 보고로 같다.
기존 여섯 긴 소편은 복사하지 않고 참조해 재사용한다. 새 분기 장면은 보충 초고이며
문체와 의미 검토는 남아 있다. 2챕터 본문은 아직 수정/집필하지 않았다.

## 분기가 어떻게 동작하는가

| 선택 | 변화 | 이후 영향 |
| --- | --- | --- |
| 무기고 먼저 / 나중 / 생략 | 방문·순서·실제 지급 기록 | 네 직업 무기 유지. 실제 동행한 비무장 매드 조에게만 원작 기본 무기 지급 |
| 지역 탐방 순서 / 일찍 출발 | 방문한 지역과 탐방 횟수 | 그곳 대사·증언만 경험. 3곳 완료하면 자동으로 출발 |
| 스켈레톤 즉시 수락 / 대화 후 결정 / 거절 | 사전 대화 경험·현재 선택 동료 | 동행한 경우만 기존 동굴/귀환 대사. 거절 후 재영입은 없음 |
| 수감소 재요청 / 일 돕기 | 접근 방식 | 매드 조의 영입 제안은 같지만 이탈 방법 선택이 달라짐 |
| 매드 조 수락 / 거절, 정문 / 조용한 이탈 | 영입 경험·현재 동료 자리·이탈 | 정문 대치에서 원작처럼 도망. 조용한 이탈은 창작 경로로 동행 유지 가능 |
| 네 동료의 직업별 방법 | 실제 동행 + 해당 무기 + 역할 활용 경험 | 동굴 진행과 귀환 보고의 보충 문단 변화 |
| 금화 찾기 / 방패 장착자 / 취소 | 지점별 일회성 기록·금액·장착자 | 실제 획득물만 귀환과 다음 챕터 인계에 남음 |

탐방 횟수는 지역 하나를 마칠 때 1회 증가한다. 지역 안에서 인사를 고르거나 대화를
더 듣는 것은 별도의 1회가 아니다. 세 곳 전에 언제든 출발할 수 있다. 세 곳을 마친
경로는 자동 출발 선택 ID도 저장하므로, 화면과 원고 재생의 사건 순서가 일치한다.
3회 제한과 이동을 잇는 새 장면은 **원작 규칙이 아닌 집필용 추가**다.

선택 동료는 원작 6번 자리 하나로 관리한다. 매드 조가 있는데 스켈레톤을 받으려면
기존 동행과 헤어짐을 확인한다. 두 선택 동료를 같은 자리에 동시에 넣지 않는다.
매드 조의 과거 영입 경험과 현재 동행 여부는 별개다. 도망간 인물이 이후 말을 하거나
같이 들은 적 없는 접견실 정보를 자동으로 아는 일을 막는다.

## 시작 동료와 무기

| 안정된 인물 ID | 현재 집필 이름/직업 | 장비 ID | 현재 표시명 |
| --- | --- | --- | --- |
| `party_woodcutter` | 나무꾼 | `story_axe` | 벌목 도끼 |
| `party_hunter` | 사냥꾼 | `story_bow` | 사냥 활 |
| `party_cook` | 요리사 | `story_knife` | 주방 칼 |
| `party_magician` | 마술사 | `story_wand` | 마술 지팡이 |

이 네 사람은 사용자 지정 집필 인물이다. 기존 원작 초기 후보 10명을 개명하거나
덮어쓰지 않았다. 인물 카드에서 원작 이름·음역·나이는 미상이고 새 이름/직업/무기는
`authored`, `addition: true`, `kind: new_setting`, `status: proposed`로 구별한다.
주인공은 공용 이름 참조를 통해 현재 **서진**으로 표시된다.

도끼는 나무받침을 살피는 데, 활은 사냥꾼의 흔적 읽기와 함께, 칼은 짐 정리에,
지팡이는 바닥과 울림 확인에 사용한다. 도끼로 원작 고정 벽을 파괴하거나 지팡이가
자동으로 원작의 모든 주문을 쓰는 설정은 추가하지 않았다. 무기 위력도 미정이다.

## 원문은 모두 어디에 있는가

보존 원문은 `../../materials/scripts.json`, 기본 본문은 `../quests/`에 있다.
[chapter01.json](chapter01.json)에는 추가 본문·원문 발생 ID·이름 위치 참조·조건·효과를
둔다. 정확한 범위는 `scope`와 `source_refs`이며 다음을 포함한다.

- LORE 성의 정적 대사: 위험 경고·소문·주점·유골·수감자·도둑·영입·문턱·격려·성주.
- MENACE 입구·중심부, 선택 금화 여섯 곳과 황금의 방패.
- 호출된 금화 표시/거절 문구와 도입부 기본 대사.

[대사 반영표](../previews/chapter01-coverage.json)는 **발생 ID별** 본문 블록/선택 ID를
가리킨다. 서로 배타적인 첫/재방문 대사·인사·수락/거절은 각 조건의 분기에 있다.
한 번의 독서에서 모든 배타 대사가 동시에 나오는 것은 아니다.
비어 있지 않은 대사/선택 라벨/문자 변수 조각이 범위 안에서 빠지면 검증이 실패한다.
빈 레이아웃·선언·제어 문자열은 이유와 함께 `non_story`로 기록한다.

이 반영 완료는 **명시한 첫 챕터 범위**에 한정된다. 공유 상점·훈련·회복·무작위 전투
메뉴와 후속 퀘스트 전체를 반영/검증했다는 뜻은 아니다. 원작에서 내부 접근 조건이
미확정인 수감소·벽 안쪽 이동은 창작 연결로 표시했다. 소설용 병사 전투 결과 선택은
게임 전투 수치 시뮬레이터가 아니다. 모든 산문의 의미 검증은 별도의 편집 작업이다.

동적 주인공 이름·금화 금액·방패 장착자는 `display_insertions`로 표시한다.
보존 문자열과 발생 ID는 그대로이고, 현재 이름/값을 넣은 표시는 각색이다.
미정 성별에 따른 원작 호칭 변수는 `[호칭 미정]`으로 남긴다. 미래 인물의 실제 합류,
마법 습득, 로드 안에 대한 최종 진상은 소문/증언을 듣는 것만으로 확정하지 않는다.

## 수정 위치와 다음 챕터 규칙

- 공용 이름: `../../reference/names.json`. 무기/인물 설정: `../../reference/analysis.json`.
- 선택 조건·효과·추가 문단: `chapter01.json`. 형식: `overlay.schema.json`.
- 작가용 설명: `branch_guide`. 독자용 동작: `reader.js`. 생성 HTML은 직접 고치지 않는다.
- 연속성: 합성 시 원래 사건/지식 계약을 유지하고 추가 사건은 경로에서만 발생한다.
  첫 방문 필수 대사를 재방문에 반복하지 않을 때는 `conditional_required`로 원문 필수
  조건을 명시한다. 조건을 바꿔 필수 대사를 숨기면 계약 검증이 실패한다.

다음 챕터는 인계 패킷의 동행/선택 자리·현재 무기 ID·역할 경험·방문 목록·들은 증언·
금화/방패 장착자·임무 단계/보상 여부를 이어받아야 한다. 카드의 전편 설정을 경로의
지식으로 복사하지 않는다. 새 장면의 동료 반응은 실제 동행 여부와 필요한 장비 ID를
함께 검사하며, 같은 영입/아이템/보상 사건을 다시 지급하지 않는다.

경로 저장 파일에는 `fingerprint`와 선택 ID 목록 `route`만 있다. 임의 소지품·지식·
미래 사건을 받아들이지 않는다. 판본이 바뀐 저장 파일은 거부한다. 저장은 사용자가
다운로드를 눌렀을 때만 실행하며, 외부 네트워크나 자동 브라우저 저장은 사용하지 않는다.
독자 HTML에는 첫 챕터 분기 원고와 공개 표시명만 넣고 전편 카드/관계/진상 마스터는
넣지 않는다. 아직 선택하지 않은 첫 챕터 분기는 화면에서 숨겨지지만 오프라인 파일의
소스를 직접 검사하면 확인할 수 있다. 비밀 보안 저장소가 아니라 집필 검토용 판본이다.

```bash
python3 tools/build_reference.py
python3 tools/writing.py validate
python3 tools/writing.py export
python3 tools/writing.py export --check
PYTHONPATH=tools python3 -m unittest discover -s tests
```
