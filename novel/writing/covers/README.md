# A/B 공용 생성형 표지

`cover-main.jpg`와 `cover-chapter01~03.jpg`는 생성형 이미지로 만든 세로 2:3 표지입니다.
A/B와 B EPUB은 **같은 파일과 해시**를 씁니다. 웹 읽기본에는 파일을 내장하므로 오프라인에서도 보입니다.
메인은 읽기 화면의 머리말, 장별 표지는 해당 장에 진입했을 때만 표시됩니다.

`manifest.json`에서 이미지 파일·해시·크기·설명·생성 의도·추가 메타를 관리합니다.
제목은 그림에 새기지 않았습니다. 책 제목은 참조 텍스트, 장 제목은 기존 장 구성에서 가져옵니다.
이름·장 제목을 바꿔도 이미지에 남은 글씨를 수정할 필요가 없습니다.

인물의 얼굴·나이·복장, 성의 건축, 봉인의 모양은 **미승인 시각화**이지 원작 확정 설정이 아닙니다.
생성 원본 PNG는 도구의 작업 공간에 보존했고, 패키지에는 크기·구도를 유지한 JPEG를 넣었습니다.
원본 PNG 경로에 대한 실행 의존성은 없습니다.

표지를 교체할 때 파일과 검토한 해시를 함께 갱신한 뒤 `python tools/writing.py export`를 실행합니다.
생성 웹·EPUB을 직접 수정하지 않습니다.
