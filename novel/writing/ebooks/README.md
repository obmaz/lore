# B안 EPUB 3.0 초고와 선택형 시험본

`generated/lore-B-chapters01-03.epub`은 B안 1~3장을 실제 선택 경로로 재생한 **선형 초고**입니다.
전자책 리더 호환성을 위해 JavaScript·선택 버튼을 넣지 않았습니다. 웹의 분기는 그대로 남아 있습니다.
모든 선택 결과를 합친 정사나 완성된 15장 소설이 아닙니다.

기존 선형 파일도 패키지 버전 `3.0`인 EPUB 3입니다. 버전 번호만으로 선택 기능이 생기지는 않습니다.
`generated/lore-B-chapters01-03-interactive-epub3.epub`은 별도의 **선택형 시험본**입니다.
`interactive.plan.json`이 출력 범위와 실험 상태를 정의하며 원고·공통 분기·A안은 변경하지 않습니다.
책의 안내 페이지나 목차에서 **선택하며 읽기**를 누르면 웹과 같은 `reader.js`가 B안 1~3장을
처리합니다. 선택 기록을 재생해 동행·장비·조건부 본문을 계산하며, 끝난 선택의 다른 결과를
자동으로 수집하지 않습니다. 되돌리기/처음부터 다시 읽기는 명시적으로 가능합니다.

스크립트가 작동하지 않거나 오래된 JavaScript 엔진이면 선택 페이지의 대체 링크로 일반 본문
또는 웹을 엽니다. 일반 본문은 기존 선형 EPUB의 동일한 대표 경로이며 선택형 결과가 아닙니다.
선택 페이지는 목차/안내에서 접근하는 비선형 스파인이고, 일반 페이지 넘김은 선형 본문을 읽습니다.
선택 기록은 `localStorage`를 허용하는 리더에서만 자동 저장합니다. 저장이 차단되어도 현재
선택과 읽기는 계속할 수 있으나 책을 닫으면 진행이 없어질 수 있습니다. 기기간/계정 동기화는 없습니다.
모든 분기 데이터가 파일 안에 있으므로 다른 갈래를 추출하지 못하게 막는 암호화 기능은 아닙니다.

## 리디 호환 조사와 실제 확인

2026-10-14 확인: [리디 공식 사용자 파일 안내](https://ridihelp.ridibooks.com/support/solutions/articles/154000207683)는
모바일/PC의 외부 EPUB 추가를 안내합니다. 하지만 EPUB 3.0 전체 기능·책에 포함된 JavaScript 실행·
저장 지원 여부는 해당 문서에 명시되어 있지 않습니다. 공식 공개 자료에서 선택형 작동을 보장하는
안내를 찾지 못했으며, 현재 **리디 앱 실기 시험은 하지 않았습니다**. EPUB 불러오기와 선택형 호환을
같은 것으로 단정하지 않습니다. [W3C 리더 규격](https://www.w3.org/TR/epub-rs-33/#sec-scripted-content)도
스크립트 지원을 필수로 요구하지 않고 저장 차단을 허용합니다.

- Android: 리디 설정 → 내 서재 및 구매목록 설정 → 사용자 파일 추가.
- iOS: 파일 앱에서 EPUB 길게 누르기 → 공유 → 리디 → 내 서재.
- 안내/목차에서 선택형 읽기를 열고 `선택 기능 작동`과 선택 버튼이 나오는지 확인합니다.
- 한 선택 뒤 책을 닫고 다시 열어 진행이 복원되는지 별도로 확인합니다.
- 작동하지 않으면 일반 본문/웹을 사용합니다. 정상 작동하더라도 OS·앱 버전별 확인이 필요합니다.

`ebook.plan.json`은 판본·범위·우선 선택·편집 날짜와 출력을 정의합니다.
현재 대표 경로는 무기고 방문 → 성문 동료 합류 → 새 동료 제안 거절 → 사냥꾼의 창 장착 →
분리해서 싸우기 → 부상자 치료/식량 제공입니다. 자동 이동은 웹과 같은 기존 실행기로 재생합니다.
선택한 소설 본문만 넣고 미선택 결과·미집필 장·전편 인물 마스터는 싣지 않습니다.

본문은 B 웹 읽기본과 같은 공용 표시 규칙·소설용 스크립트 대체본·이름 참조를 적용합니다.
소단락 제목과 화자 이름표는 없고 장 제목만 있습니다. 메인/1~3장 공용 표지와 EPUB 3 목차,
구형 리더용 NCX, 원고 범위 안내를 포함합니다. 표지 그림은 새 확정 외형으로 취급하지 않습니다.

갱신과 검증은 `novel/`에서 실행합니다.

```sh
python tools/writing.py export
python tools/writing.py export --check
python tools/ebook.py --check
```

`generated/manifest.json`은 B 웹 읽기본·편집 입력·공용 실행기·표지의 해시와 두 EPUB 출력 해시를 지킵니다.
`report.json`에는 실제 선택 ID·필수 본줄기·선택 경로의 원문 반영·장별 분량을 기록합니다.
ZIP 날짜와 식별자는 입력 기반으로 고정해 재검증할 때 같은 바이트가 나오게 했습니다.
생성물을 수동 수정하면 덮어쓰기 전에 멈춥니다.

`interactive-report.json`에는 공통 실행기·분기 데이터 범위·필수 본줄기 43개·대체 경로·
선택 기록 형식·리디 미검증을 기록합니다. 패키지/브라우저 검사는 전용 리더 실기 검사를 대신하지 않습니다.
