# B안 EPUB 초고

`generated/lore-B-chapters01-03.epub`은 B안 1~3장을 실제 선택 경로로 재생한 **선형 초고**입니다.
전자책 리더 호환성을 위해 JavaScript·선택 버튼을 넣지 않았습니다. 웹의 분기는 그대로 남아 있습니다.
모든 선택 결과를 합친 정사나 완성된 15장 소설이 아닙니다.

`ebook.plan.json`은 판본·범위·우선 선택·편집 날짜와 출력을 정의합니다.
현재 대표 경로는 무기고 방문 → 성문 동료 합류 → 새 동료 제안 거절 → 사냥꾼의 창 장착 →
분리해서 싸우기 → 부상자 치료/식량 제공입니다. 자동 이동은 웹과 같은 기존 실행기로 재생합니다.
선택한 소설 본문만 넣고 미선택 결과·미집필 장·전편 인물 마스터는 싣지 않습니다.

본문은 B 웹 읽기본과 같은 공용 표시 규칙·소설용 스크립트 대체본·이름 참조를 적용합니다.
소단락 제목과 화자 이름표는 없고 장 제목만 있습니다. 메인/1~3장 공용 표지와 EPUB 3 목차,
구형 리더용 NCX, 원고 범위 안내를 포함합니다. 표지 그림은 새 확정 외형으로 취급하지 않습니다.

갱신과 검증은 `novel/`에서 실행합니다.

```sh
python tools/writing.py export
python tools/writing.py export --check
python tools/ebook.py --check
```

`generated/manifest.json`은 B 웹 읽기본·편집 입력·표지의 해시와 EPUB 출력 해시를 지킵니다.
`report.json`에는 실제 선택 ID·필수 본줄기·선택 경로의 원문 반영·장별 분량을 기록합니다.
ZIP 날짜와 식별자는 입력 기반으로 고정해 재검증할 때 같은 바이트가 나오게 했습니다.
생성물을 수동 수정하면 덮어쓰기 전에 멈춥니다.
