# 동료 합류 전용 이벤트

`series.json`은 동료가 실제로 현재 파티에 합류한 경로에서만 읽는 작가용 전용 장면 원본이다.
인물 카드의 고정 설정과 분리해, 합류 시점·동행 조건·직업/장비를 활용한 장면·이후 반응을 관리한다.

모든 항목은 원작에 없는 집필 추가이므로 `origin: authored`, `status: proposed`,
`metadata.addition: true`를 가진다. `companion_ref`와 `equipment_ref`는 이름 문자열이 아니라
안정된 참조 ID다. 표시명이나 무기를 바꾸면 이 파일의 본문을 재작성하지 않고 참조 렌더링을 갱신한다.

## 이벤트 규칙

- `join_trigger`가 성립한 현재 경로에서만 이벤트를 연다. 영입 제안을 들은 것과 실제 합류를 구분한다.
- 시작 동료 4명은 첫 출발 뒤 각각의 장면을 갖고, 선택 동료 `skeleton`과 `spica`는 실제 영입 선택 뒤에만 갖는다.
- 이벤트는 `main_state_writes: []`다. 본줄기 열쇠·봉인·지식·장비·필수 사건을 선지급하지 않는다.
- `equipment_ref`는 현재 장착 장비를 장면에 반영하기 위한 참조다. 이벤트가 장비를 지급하거나 교체하지 않는다. 원작 자료에 합류 시 장비가 확정되지 않은 동료는 `null`로 두고 임의의 장비를 만들지 않는다.
- `follow_up`은 이후 장에서 같은 동료가 합류해 있던 경로에만 나타나는 짧은 반응이다. 합류하지 않은 동료의 기억을 만들지 않는다.
- 원작 대사를 대체하지 않는다. 이 파일의 대사는 창작 초고로 표시되며, 원작 연결 판본은 별도로 보존된다.

```text
합류 조건 확인 → 동료 전용 장면 → 본줄기 재합류
                         └→ 이후 해당 동료가 실제 동행한 경로에만 후속 반응
```

이벤트 본문은 장편 본문 승인이 아니라 `outline` 단계의 집필 재료다.
