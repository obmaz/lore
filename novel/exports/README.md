# 읽기 전용 참고 문서

- `reference.html`: 인터넷·서버 없이 여는 단일 HTML. 처음에는 초안 경로의 공개
  범위만 표시한다. **작가용 전체 설정 열기**를 선택하면 인물·관계·장비·마법·적
  템플릿·퀘스트 흐름·공개 정책을 모두 읽고 검색할 수 있다.
- `reference-author.pdf`: 작가용 전체 설정의 A4 PDF. **전편 스포일러 포함**이다.
  휴대폰에서 빠르게 참고하거나 오프라인으로 보관할 때 사용한다.
- `reference-safe.html`: 같은 초안 경로에 허용된 카드/참조만 담은 별도 파일.
  작가용 원본·비공개 관계·미래 인물 목록을 넣지 않는다. 초안의 공개 미리보기이지
  출판 승인된 소개 자료는 아니다.
- `manifest.json`: 설정 revision, 선택 경로, 원본 JSON/출력 도구 해시, PDF 해시.

작가용 HTML은 숨겨진 전체 내용을 **파일 안에 포함**한다. 접힌 UI는 접근 제어가
아니므로 공유하지 않는다. 공유용으로는 별도로 필터된 `reference-safe.html`을 사용한다.
두 HTML 모두 외부 스크립트·폰트·분석 도구 없이 동작하며 조회만 가능하다.
자동으로 공개 웹사이트에 배포하거나 GitHub Pages 설정을 바꾸지 않는다.

HTML을 내려받아 브라우저로 열면 목차·검색·펼치기가 가능하다. **인쇄 / PDF 저장**은
현재 공개/작가 보기의 전체 항목을 펼쳐 인쇄하며 검색으로 숨겼던 항목도 포함한다.
작가용 보기에서 인쇄하면 스포일러 포함, 공개 보기에서 인쇄하면 공개 범위만 포함한다.
JavaScript를 끄면 최초 공개 보기만 읽을 수 있다.

원문 전체 대사는 `../materials/` JSON에 그대로 있고, 여기에는 설정 요약만 싣는다.
원문에 없는 설정·추론·음역의 추가 표시를 보존한다. 증언/문서의 주장과 세계의
확정 사실, 현재 동료/소지품/지식을 구분하며 적 수치는 나이로 취급하지 않는다.
퀘스트 목록 순서는 강제 진행 순서가 아니고 연결 종류·병렬 조건을 함께 확인한다.

## 재생성

`novel/`에서 실행한다. JSON은 기준 자료이고 이 문서들은 수정 불가 스냅샷이다.
자료를 고친 뒤 다시 생성·커밋해야 반영된다. 게임 빌드는 하지 않는다.

```bash
python3 tools/export_reference.py --pdf
python3 tools/export_reference.py --check
python3 tools/check_reference_browser.py
```

HTML 생성에는 기존 `requirements.txt`만 필요하다. `--pdf`는 추가로 Python Playwright와
`/usr/bin/chromium`, 한국어 폰트가 설치된 환경에서 사용한다. 없는 환경에서는 새 출력
폴더에 HTML만 생성하고 브라우저 인쇄로 PDF를 저장할 수 있다.
선택적인 브라우저 검증 도구도 Playwright와 Chromium을 사용한다. 모바일/데스크톱
레이아웃·검색·작가 모드·인쇄 후 복원·외부 요청 없음을 검사한다.

```bash
python3 tools/export_reference.py --output /tmp/lore-reference
```

기존 PDF가 있는 폴더는 `--pdf` 없이 재생성하지 못하게 하여 오래된 PDF를 최신으로
오인하지 않도록 한다. `--check`는 JSON과 HTML의 일치 및 저장된 PDF 해시를 검사한다.
UI 모드 전환은 집필 공개 사건을 바꾸지 않으며 원본 게임·집필 JSON을 수정하지 않는다.
