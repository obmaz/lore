# Project scope

- Unless the user explicitly names another project, apply game changes only to
  `remake/`. Changes to `original/` or `novel/` require an explicit request.
- `original/`, `remake/`, and `novel/` are independent projects. Do not introduce
  runtime, asset, tooling, or source-data dependencies between them.
- Read the selected project's `AGENTS.md` before changing that project.
- All projects are maintained on `main`; keep unrelated user changes intact.
