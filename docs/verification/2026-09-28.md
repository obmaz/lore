# 원작 이식 검증 기록 (2026-09-28)

## 판정

**원작 완전 이식으로 판정할 수 없다.** 앱 회귀 테스트와 정적 분석은 통과했지만,
원본과 동일한 상태·입력·난수에서 모든 관찰 가능한 효과가 일치한다는 증거가
부족하다. `docs/porting/direct_port_strategy.md`의 최종 게이트는 열려 있다.

## 추가 원본 절차 분석

`docs/source/procedure_traces.md`에 절차 간 재생 경로를 기록했다.
맵 6 대화가 특수 타일을 만들고, 맵 23 전투가 표지판·사건·출구를
차례로 여는 경로는 정적 `.MAP` 또는 단일 절차만으로 닫히지 않는다.
`LORESPEC` 내부의 `Load`도 지도 전환 경로다.

전투에서는 **확정된 포트 실행 순서·상태 차이** 세 건을 찾았다.
원본은 아군 전원의 명령을 예약하고 모두 실행한 뒤 적 단계 다음에
승패를 판정한다 (`LOREBATT.PAS:1011-1175`). 현재
`lib/widgets/battle_viewport_view.dart:159-165`는 아군 한 명의
행동 직후 종료를 검사한다. 원본의 자동전투 선택은 라운드마다
초기화되지만 포트는 다음 라운드까지 토글을 유지한다
(`LOREBATT.PAS:1011-1035`, `battle_viewport_view.dart:546-610`).
원본 `ReturnCondition`은 조회할 때 HP≤0을 의식불명으로 전환하므로
적 피해와 상태 표시 사이에 중간 상태가 존재한다
(`LORESUB.PAS:706-725`). 포트는 적 피해 순간 상태를 바꾸고 음수 HP를
0으로 고정한다 (`lib/logic/battle_engine.dart:1319-1323,1379-1383`).
메뉴가 전역 키 `c`를 바꿔 같은 입력의 타일 재판정 여부가 달라지는
구조도 소스에서 확인했다. 이 분석에서 포트 코드는 변경하지 않았다.
위 자동 검사 결과는 앞선 코드 검증 결과이며 새 차이의 해결 증거가 아니다.

`docs/source/state_lifecycle.md`에서 이야기 단계 `[10,13,14,15]`의
대화·던전 사건 전이를 연결했다. 원본 지도는 일반 재입장 때 기본
`.MAP`을 읽고, 입장 경로가 비트·동료 이름·단계값에 따라 일부 타일을
다시 쓴다. 맵 6에는 입장 경로만으로 열리는 타일도 있다.

필드에는 공통 시간 틱이 없다. 일반 이동, 물, 늪, 용암이 각각 다른
상태·난수 비용을 가진다. `GameOver`는 저장 슬롯을 동기식으로
불러온 뒤 호출자에게 반환할 수 있다. 일반 이동의 독 전멸 뒤
맵 14 `(25,45)`의 타일 44로 복원하면, 조우 난수가 비적중일 때 같은
입력에서 던전 `Move_Mode`까지 다시 실행되는 소스 경로를 확인했다.
현재 포트의 `gameOver` 콜백은 화면 모드만 바꾸므로
(`main_game_screen.dart:238-255`), 조우 난수가 적중하면 이어지는
`_startBattle`이 모드를 `encounter`로 다시 바꿀 수 있다
(`:1342-1351`). 복원·재개 계약과 함께 수정 대상이다. 이 경로는
제공된 EXE에서는 재생하지 않았다.

## 남은 검증 분모

- 계약 장부의 게임 제어 지점 **1,848개 미검증**, 이 중 부분 근거 6개와
  검증 완료 0개. 이 수치는 개별 구현 과제 수가 아니라 누락 감시용 구문 수다.
- 원본 지도 쓰기 **123개**는 조건·좌표·효과의 검증 근거와 아직 연결되지 않았다.
- 비활성 JSON 중 활성 규칙·포털과 겹치지 않는 항목 **28개**가 감사 보고서에
  남는다. 맵 6의 원본 자동 추출 조각 27개와 맵 22의 남쪽 구역 1개다.
  맵 22 남쪽 조각은 현재 지도 이동 경계 밖이라는 테스트가 있다. 맵 6 조각은
  원본형 처리와 효과를 대조해 보관·중복·누락으로 분류해야 한다.
- 활성 전투 스크립트 42개 중 `source_parity.json`이 선택하는 고유 ID는 21개다.
  다른 테스트의 근거도 있으므로 나머지를 모두 미구현으로 보지 않는다.
- 저장·재방문, 전투 승리/도주/패배 후속, 시작부터 엔딩까지의 결정적 재생,
  실제 화면·오디오 경로의 원본 대조가 완료 게이트에 필요하다.

## 다음 검증 순서

1. `LOREMAIN.Main`의 한 입력 안에서 지도 종류가 바뀌는 경로와
   메뉴가 전역 키 `c`를 바꾸는 경로를 원본 지도 바이트와 상태로
   재생한다. 맵 1→14처럼 입장 후 도착 타일의
   `Move_Mode`가 실행되는지 확인하고 포트의 확정된 차이를 해결한다.
2. `BattleMode`의 라운드 예약·즉시 치료·남은 아군 행동·적 턴·종료
   순서, 라운드 한정 자동전투, 상태 표시의 전이 시점을 실제 전투
   화면에서 재생해 차이를 해결한다.
3. 원본 루틴 단위로 조건·상태·순서 있는 효과를 명세하고, 이식 경로와
   재생 테스트에 연결한다. 이야기 단계 네 종류와 지도 입장 패치를
   공유 상태 계약으로 고정하고, `LORESPEC` 맵 6의 보관 조각과 맵 22의 추가
   타일 상태도 분류한다.
4. 지도 쓰기와 전투 후속을 같은 장부에 연결하고, 난수·선택·도주·패배를
   고정 입력으로 검사한다.
5. 27개 지도의 진입·출구·사건·재방문과 공통 규칙을 통과시킨 뒤
   새 게임→엔딩 및 저장 왕복을 실제 앱과 세션에서 확인한다.

테스트 통과는 이식 코드의 내부 회귀를 뜻한다. 원본 동등성 판정은 각 결과에
원본 코드 또는 원본 실행 흔적과 독립적인 기대 결과를 연결한 뒤에만 올린다.
