# 실제 플레이 점검 기록

자동화된 상태 비교와 별도로, 실제 웹 화면에서 키보드 입력으로 진행한 기록이다.
발견 즉시 항목을 추가하며, 중간 중지 시에도 마지막 단계까지 보존한다.

## 2026-10-10

- 시작: 로컬 Pages 빌드(`docs/`)를 Chromium에서 실행.
- 현재 단계: 새 게임 생성 진입 전.
- 이상: 첫 실행을 `/`에서 열어 `/lore/` base 경로 자원이 로드되지 않음. 게임 이상으로 분류하지 않고 실행 경로를 수정.
- `/lore/` 경로에서 재실행: 원본 오프닝을 넘기고 새 주인공 이름 입력까지 정상.
- 실제 브라우저 진행: 질문·동료 생성, 첫 퀘스트, 무기고, Skeleton departure, 저장 후 재개까지 정상.
- 자동 입력 보조로 확인한 화면 흐름: GameOption Esc, 저장 슬롯 Esc, Rest Esc, 성문 선택의 Esc·거절·입장 모두 정상.
- 이상: 게임 로직 이상 없음. 첫 실행 경로 문제는 재현 환경 문제로만 기록.
